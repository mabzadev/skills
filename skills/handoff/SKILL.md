---
name: handoff
description: "Compactez la conversation en cours dans un document de transfert pour qu'un autre agent puisse la récupérer."
---

Rédigez un document de transfert résumant la conversation en cours afin qu'un nouvel agent puisse continuer le travail. Enregistrez dans le répertoire temporaire du système d’exploitation de l’utilisateur – et non dans l’espace de travail actuel.

Incluez une section « compétences suggérées » dans le document, qui suggère les compétences que l'agent doit invoquer.

Ne dupliquez pas le contenu déjà capturé dans d'autres artefacts (spécifications, plans, ADR, problèmes, validations, différences). Référencez-les plutôt par chemin ou URL.

Supprimez toutes les informations sensibles, telles que les clés API, les mots de passe ou les informations personnelles identifiables.

Si l'utilisateur a transmis des arguments, traitez-les comme une description de ce sur quoi la prochaine session se concentrera et adaptez le document en conséquence.
