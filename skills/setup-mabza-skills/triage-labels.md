# Étiquettes de triage

Les compétences parlent en termes de cinq rôles canoniques de tri. Ce fichier associe ces rôles aux chaînes d'étiquettes réelles utilisées dans le suivi des problèmes de ce dépôt.

| Étiquette dans mbzadev/compétences | Étiquette dans notre outil de suivi | Signification |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`  | `needs-triage`  | Le responsable doit évaluer ce problème |
| `needs-info`  | `needs-info`  | En attente d’informations de la part de l’auteur du ticket |
| `ready-for-agent`  | `ready-for-agent`  | Entièrement spécifié, prêt pour un agent AFK |
| `ready-for-human`  | `ready-for-human`  | Nécessite une mise en œuvre humaine |
| `wontfix`  | `wontfix`  | Ne sera pas donné suite |

Lorsqu'une compétence mentionne un rôle (par exemple « appliquer l'étiquette de tri prête pour AFK »), utilisez la chaîne d'étiquette correspondante de ce tableau.

Modifiez la colonne de droite pour qu'elle corresponde au vocabulaire que vous utilisez réellement.
